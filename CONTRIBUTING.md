# Contributing

Thank you for helping improve Habitica Time Ledger.

## Reporting bugs

Before opening an issue:

1. Confirm that the latest version is installed.
2. Reload the extension from `chrome://extensions`.
3. Refresh the Habitica webpage with `Ctrl + Shift + R`.
4. Reproduce the issue once more.

A useful bug report includes:

- Chrome or Chromium browser version
- extension version
- affected task type: Habit, Daily, or To-Do
- whether the record appeared as `Web exact`, `DOM fallback`, or `Synced`
- clear reproduction steps
- screenshots with personal information removed

Never include your Habitica User ID, API Token, private task content, or full browser-storage export in a public issue.

## Feature requests

Describe the workflow problem first, then the proposed feature. Time Ledger aims to stay lightweight and keep Habitica as the main task interface.

## Local development

1. Clone the repository.
2. Open `chrome://extensions`.
3. Enable **Developer mode**.
4. Click **Load unpacked** and select the repository root.
5. After code changes, click **Reload** on the extension card.
6. Refresh open Habitica tabs.

## Pull requests

Keep changes focused and avoid introducing remote scripts, analytics, advertising, or unnecessary permissions. Update `CHANGELOG.md` for user-visible changes.
