# Privacy Policy

**Effective date:** July 26, 2026

Habitica Time Ledger is an independent browser extension that converts Habitica task completions into local activity analytics.

## Data processed

The extension may process the following information when you choose to connect a Habitica account:

- Habitica User ID
- Habitica API Token
- Habitica task names, identifiers, types, tags, and completion states
- User-defined categories, projects, and minutes per completion
- Task-completion timestamps and locally generated activity records
- Extension preferences, including theme and sync settings

## How data is used

This information is used only to:

- authenticate requests to Habitica's official API
- synchronize tasks and task states
- recognize task-completion events
- create the activity timeline and category/project analytics
- remember task setup and extension preferences

## Storage

Habitica Time Ledger does not operate an external server or analytics backend.

Credentials, task configuration, and activity records are stored locally using Chrome extension storage on the user's browser profile. Local browser storage is not described as encrypted storage and should not be treated as a password vault.

## Data transmission

Habitica credentials and task-related requests are transmitted only to Habitica's official service for the purpose of synchronization and authentication.

The extension does not transmit user data to the developer, advertisers, analytics companies, data brokers, or other third parties.

## Selling or sharing data

Habitica Time Ledger does not:

- sell personal data
- use personal data for advertising
- share personal data with data brokers
- use task data for cross-site tracking
- create behavioral advertising profiles

## Data retention and deletion

Data remains in the user's Chrome extension storage until it is cleared by the user or removed when the extension is uninstalled, subject to Chrome's own storage behavior.

Users can remove locally stored activity and configuration data from the extension's settings or by uninstalling the extension. Users may also revoke or regenerate their Habitica API Token from Habitica settings.

## Security guidance

Treat your Habitica API Token like a password. Do not post it in public GitHub issues, screenshots, logs, or commits. If a token may have been exposed, regenerate it in Habitica immediately.

## Children's privacy

Habitica Time Ledger is not designed to knowingly collect personal information from children. The extension does not operate an external collection service.

## Changes to this policy

Material changes will be documented in this repository and reflected by updating the effective date above.

## Contact

Questions or privacy concerns can be raised through the GitHub repository's Issues page. Do not include API Tokens or other credentials in a public issue.

## Relationship to Habitica

Habitica Time Ledger is an unofficial companion extension and is not affiliated with or endorsed by Habitica. Habitica's own processing of account data is governed by Habitica's policies.
